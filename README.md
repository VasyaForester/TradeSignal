# TradeSignal

Статический дашборд сигналов только по российскому биржевому рынку: акции, облигации и биржевые фонды Московской биржи.

## Что уже работает

- топ-10 акций по полной ожидаемой доходности: таргет модели TradeSignal + прогнозный дивиденд;
- топ-10 облигаций: до 5 ОФЗ и до 5 ликвидных выпусков крупных корпоративных и квазигосударственных эмитентов;
- топ-10 фондов по классам (денежный рынок, облигации, золото, акции): carry от ставки и/или импульс 3/12 мес.;
- до 10 срочных сигналов за последние 36 часов: только для конкретной акции или облигации, с entity confidence, sentiment, сценарной оценкой влияния и объединением дублей;
- дата снимка, уверенность, риск и ссылка на источник;
- автоматическое обновление и публикация в GitHub Pages через Actions.

## Источники

- [MOEX ISS](https://iss.moex.com/iss/reference/) — котировки, параметры облигаций и исторические свечи;
- [Банк России](https://www.cbr.ru/development/rss/) — официальные пресс-релизы;
- [Интерфакс](https://www.interfax.ru/rss), [Коммерсантъ](https://www.kommersant.ru/rss-list), [Ведомости](https://www.vedomosti.ru/rss/news) и [РБК](https://rssexport.rbc.ru/rbcnews/news/30/full.rss) — публичные новостные RSS;
- RSS [Финама](https://www.finam.ru/rsspoint/list/) по компаниям и облигациям и лента [Investing.com](https://ru.investing.com/rss/news_25.rss);
- официальные RSS пресс-центров [Газпрома](https://www.gazprom.ru/rss/) и [Роснефти](https://www.rosneft.ru/press/releases/rss/);
- публичная веб-лента Telegram-канала [MarketTwits](https://t.me/markettwits) — дополнительный best-effort источник; посты без конкретного российского тикера или ISIN отбрасываются;
## Модель таргетов акций

Целевая цена больше не копируется из старых стратегий брокеров. При каждом запуске Actions модель `tradesignal-v1` считает 12‑месячный таргет:

1. текущая цена MOEX;
2. импульс 3/12 месяцев по дневным свечам;
3. качество бизнеса (`financialTrend`) и сектор из `config/forecasts.json`;
4. свежие срочные новостные сигналы по тому же тикеру;
5. сценарное снижение ключевой ставки;
6. clamp роста цены примерно −35%…+55%, затем `expectedReturn = рост + дивиденд`.

В `config/forecasts.json` хранятся только priors: дивиденд, тезис, риски, сектор. Опциональный ручной `targetPrice` может переопределить модель, но по умолчанию не задан. Платный ЦКИ MOEX намеренно не используется.

## Обработка новостей

1. Ленты загружаются параллельно с retry/backoff; отказ одного источника не останавливает снимок.
2. Явные тикеры и ISIN имеют приоритет, затем используется версия базы алиасов `config/entities.json`. Привязка выполняется по заголовку, чтобы упоминание аналитика в тексте не стало целевой компанией.
3. Новости группируются по тикеру и направлению. Дубли определяются по Jaccard-сходству текстовых шинглов или одинаковому типу события в 36-часовом окне; все первоисточники сохраняются.
4. Правиловая модель `rules-v1` возвращает sentiment `-1..1`, сценарную реакцию цены и уверенность с учетом силы события, качества entity linking и приоритета источника.
5. В снимок записываются `dedup-rate`, число отфильтрованных материалов, latency, а также precision/recall entity linking на контрольной выборке `config/entity-eval.json`. Accuracy влияния пока не публикуется: для нее сначала нужна размеченная история фактических движений.

Celery, Redis и PostgreSQL намеренно не добавлены: текущий конвейер запускается периодическим одноразовым GitHub Actions job, поэтому постоянные брокеры и кэш потребовали бы отдельной платной инфраструктуры без ускорения этого сценария.

## Локальный запуск

```powershell
python scripts/update_data.py
python -m unittest discover -s tests -v
python -m http.server 8000
```

Откройте `http://localhost:8000`. Прямое открытие `index.html` может блокировать загрузку JSON из-за политики браузера.

## GitHub Pages

1. В репозитории откройте **Settings → Pages**.
2. В **Build and deployment → Source** выберите **GitHub Actions**.
3. Запустите workflow **Update market data and deploy** вручную.

Workflow также запускается каждые 2 часа в торговое время по будням и при push в `main`. Обновленный JSON публикуется в Pages как artifact; исходный файл в ветке при этом не коммитится автоматически.

## Лицензирование данных

Бесплатный MOEX ISS обычно отдает котировки с задержкой и подходит для прототипа и ознакомительного использования. Условия MOEX ограничивают создание публичных информационных продуктов для третьих лиц. Перед публичным или коммерческим запуском необходимо письменно согласовать с Московской биржей режим использования и распространения данных. Real-time котировки и стакан требуют договорного доступа.

Аналогично, массовая отчетность, полный аналитический консенсус и единая лента обязательных раскрытий не имеют надежного бесплатного официального API. Для промышленной версии эти блоки должны подключаться через лицензированных провайдеров.

## Модель и ограничения

Акции сортируются по полной доходности модели TradeSignal, а не по консенсусу брокеров. Облигационная оценка использует приближение через дюрацию и не заменяет точный расчет денежных потоков. Модель фондов экстраполирует тренд. Новостные sentiment и impact — эвристические сценарные оценки, а не обученный прогноз цены; сигнал остается только поводом проверить первоисточник.

Проект не является инвестиционной рекомендацией и не исполняет сделки.
